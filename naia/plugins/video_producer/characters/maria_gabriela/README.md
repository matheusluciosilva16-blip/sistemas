# Maria Gabriela

Personagem fictícia (`"fictional": true` em `character.json`).

## Imagens de referência (ainda não enviadas)

Coloque nesta pasta, em PNG, as imagens que o Veo vai usar para manter o rosto
igual entre as cenas:

- `face_front.png` — rosto de frente
- `face_side.png` — rosto de perfil
- `face_3quarter.png` — rosto em três quartos
- `full_body.png` — corpo inteiro com a roupa padrão

Sem elas, cada cena gera uma Maria Gabriela um pouco diferente.

## Voz

Preencha `voice_id` em `voice.json` com o ID da voz escolhida na ElevenLabs,
ou defina `ELEVENLABS_VOICE_ID` no `.env` da VPS.
